1Propósito

Convierte una alerta de contaminación ya detectada por satélite (Capa 1) en una estimación cuantificada del impacto humano, ecológico y económico, con intervalos de confianza honestos y trazabilidad completa para la denuncia ante OEFA.

Lo que NO hace: no mide la contaminación (eso lo hace Claude Vision en la Capa 1), no predice si habrá derrame, no reemplaza al perito ambiental. Genera un punto de partida cuantificado que el perito refina en campo.

6Cómo predice — paso a paso

Cuando llega un alert al endpoint POST /predict/{alert_id}, el pipeline ejecuta 6 pasos en ~30-50 milisegundos:

1
Recibe el alert document desde Firestore
{ contamination_type, sentinel_bbox, confidence, detected_at, attribution }
↓
2
feature_extraction.features_from_alert(doc, attribution)
bbox → centroide → nearest_district() → DISTRICT_GEO lookup
bbox area × confidence × 100 → volume_barrels (cap 6,000)
detected_at.month → get_season()
attribution.distance_to_pipeline_km (con fallback)
→ { features: [7 floats], _provenance: {...}, _derived_inputs: {...} }
↓
3
model.predict([features])[0] → 4 valores
[people_7d, people_30d, fish%, recovery]
Clamp físico: people ≥ 0 · fish ∈ [0,100] · recovery ≥ 1 día
↓
4
Bootstrap CI — 20 modelos votan
P5/P50/P95 por target
ci_result["intervals"] = { target: { p5, p95 }, ... }
↓
5
Cálculos derivados
drinking_water_sources_at_risk = bbox_area_km² / 25
economic_damage_usd = people_30d × $200 + recovery_days × $5,000
↓
6
Update Firestore con 4 campos siblings
predictions: { 6 valores ImpactPrediction }
predictions_intervals: { P5/P95 por target }
feature_provenance: { fuente documentada por feature }
derived_inputs: { valores intermedios para auditoría }
